# Sheep and Owl detection
**Project introduction:**
The aim of this project is develop and fine-tunine a custom AI model designed to detect and locate two specific objects: sheep and owls using the YOLOv8 (You Only Look Once) framework. The dataset used for training is OpenImagesV7, which contains labeled images of various objects, including sheep and owls.

Repository includes:
* Notebook YOLOv8-SheepAndOwls.ipynb contains the full code used for fine-tuning models and downloading datasets as well as a section that allows for making predictions on any images.This notebook was created using Google Colab and is designed to be used within the Google Colab environment. 
* The weights for the best model best_model.pt
* .yaml files for dataset with and without augmentations.
* zip file containing the output of the last successful training (last_run)
* Photo that can be used for testing the model
